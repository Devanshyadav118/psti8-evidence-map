## Context

The repository contains curated preclinical datasets, analytical Python scripts, statistical power models, and scholarly literature review notes on PSTi8 and pancreastatin. A formal open license is required to define reuse permissions, attribution requirements, and intellectual property boundaries.

## Decision

1. **License Selection:** Adopt the **Creative Commons Attribution 4.0 International Public License (CC BY 4.0)** for the entire repository, including all datasets, documentation, scholarly notes, and executable analysis code in `scripts/`.
2. **Copyright Holder:** Devansh Pratap Singh.
3. **Full Legal Text:** Preserved in the root `LICENSE` file.
4. **Attribution Requirement:** Anyone sharing, adapting, or building upon this repository must attribute the work to Devansh Pratap Singh with a link to the repository (`https://github.com/Devanshyadav118/psti8-evidence-map`).
5. **Third-Party Literature Boundary:** Explicitly note that cited scientific publications, journal articles, and publisher materials remain under their publishers' and authors' copyright; this repository provides only extracted summary values, metadata, and original paraphrased scholarly notes.
