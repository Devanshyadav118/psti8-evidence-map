# Search Log

**Purpose:** Record every literature search performed during Phase 1, for reproducibility.

---

## Log Format

Each entry records:

| Field | Description |
|-------|-------------|
| Date | YYYY-MM-DD |
| Thread | Topic thread number (1–6) |
| Database | PubMed, Google Scholar, bioRxiv, etc. |
| Query | Exact search string used |
| Filters | Date range, article type, language, etc. |
| Results | Total hits returned |
| Screened | Number of titles/abstracts screened |
| Included | Number added to `papers_registry.csv` |
| Notes | Any observations about yield, saturation, or problems |
